   - post type key: 'speekr_speaker'
   - label: __('Speaker Profile', 'speekr')
   - singular_name: __('Speaker Profile', 'speekr')
   - public: true
   - show_ui: true
   - show_in_rest: true          ← mandatory for block editor
   - menu_icon: 'dashicons-id'
   - menu_position: 7
   - capability_type: 'post'
   - supports: array('title', 'editor', 'thumbnail', 'custom-fields', 'revisions')
     — 'editor' and 'custom-fields' are mandatory for block editor + REST meta access
   - rewrite: array('slug' => 'speaker-profile', 'with_front' => false)
   - show_in_nav_menus: false
   - has_archive: false

3. A function speekr_register_speaker_profile_meta() hooked to 'init' that calls register_post_meta() five times for post type 'speekr_speaker':

   Field 1 — _speekr_headshots (array of objects):
   ```php
   register_post_meta('speekr_speaker', '_speekr_headshots', array(
       'single'            => true,
       'type'              => 'array',
       'show_in_rest'      => array(
           'schema' => array(
               'type'  => 'array',
               'items' => array(
                   'type'                 => 'object',
                   'additionalProperties' => false,
                   'properties'           => array(
                       'id'    => array('type' => 'integer', 'minimum' => 1),
                       'label' => array('type' => 'string'),
                   ),
               ),
           ),
       ),
       'sanitize_callback' => 'speekr_sanitize_headshots',
       'auth_callback'     => function() { return current_user_can('edit_posts'); },
   ));
   ```
   Also define function speekr_sanitize_headshots($value) that iterates the array and ensures each item has 'id' (absint) and 'label' (sanitize_text_field), returning the clean array.

   Field 2 — _speekr_bio_short (plain string):
   ```php
   register_post_meta('speekr_speaker', '_speekr_bio_short', array(
       'single'            => true,
       'type'              => 'string',
       'show_in_rest'      => true,
       'sanitize_callback' => 'sanitize_textarea_field',
       'auth_callback'     => function() { return current_user_can('edit_posts'); },
   ));
   ```

   Field 3 — _speekr_bio_long (plain string):
   ```php
   register_post_meta('speekr_speaker', '_speekr_bio_long', array(
       'single'            => true,
       'type'              => 'string',
       'show_in_rest'      => true,
       'sanitize_callback' => 'sanitize_textarea_field',
       'auth_callback'     => function() { return current_user_can('edit_posts'); },
   ));
   ```

   Field 4 — _speekr_social_links (array of objects):
   ```php
   register_post_meta('speekr_speaker', '_speekr_social_links', array(
       'single'            => true,
       'type'              => 'array',
       'show_in_rest'      => array(
           'schema' => array(
               'type'  => 'array',
               'items' => array(
                   'type'                 => 'object',
                   'additionalProperties' => false,
                   'properties'           => array(
                       'platform' => array('type' => 'string'),
                       'url'      => array('type' => 'string', 'format' => 'uri'),
                       'label'    => array('type' => 'string'),
                   ),
               ),
           ),
       ),
       'sanitize_callback' => 'speekr_sanitize_social_links',
       'auth_callback'     => function() { return current_user_can('edit_posts'); },
   ));
   ```
   Also define function speekr_sanitize_social_links($value) that iterates the array and ensures each item has 'platform' (sanitize_text_field), 'url' (esc_url_raw), and 'label' (sanitize_text_field).

   Field 5 — _speekr_rider (single object):
   ```php
   register_post_meta('speekr_speaker', '_speekr_rider', array(
       'single'            => true,
       'type'              => 'object',
       'show_in_rest'      => array(
           'schema' => array(
               'type'                 => 'object',
               'additionalProperties' => false,
               'properties'           => array(
                   'av'            => array('type' => 'string'),
                   'travel'        => array('type' => 'string'),
                   'dietary'       => array('type' => 'string'),
                   'accessibility' => array('type' => 'string'),
               ),
           ),
       ),
       'sanitize_callback' => 'speekr_sanitize_rider',
       'auth_callback'     => function() { return current_user_can('edit_posts'); },
   ));
   ```
   Also define function speekr_sanitize_rider($value) that ensures the object has keys 'av', 'travel', 'dietary', 'accessibility', each passed through sanitize_textarea_field.

NOTE on additionalProperties: false — if REST saves are rejected, remove this from _speekr_headshots and _speekr_social_links items schema in Plan 03 verification. Leave it in for now as it provides schema strictness.
