<objective>
Build the Talk meta block — three editable panels (Summary, Media Links, Conference) plus one read-only reverse-lookup panel (Appears In) — as a PluginDocumentSettingPanel plugin registered on the 'talks' post type.

Purpose: Speakers can enter and edit all Talk metadata in the block editor sidebar without classic meta boxes. The panels save via REST to meta keys registered in Plan 03-01.

Output: src/blocks/talk-meta/ (block.json, index.js, edit.js)

DEVIATION NOTE: CONTEXT.md originally specified RichText for the summary field. Research (03-RESEARCH.md) confirmed RichText is broken in PluginDocumentSettingPanel since WP 6.5 (Gutenberg issue #60524, still unresolved in WP 6.9.1). This plan uses TextareaControl for the summary field instead. The stored data remains plain text; rich text formatting can be layered at render time in Phase 4 if needed. The schema (sanitize_textarea_field) already supports this upgrade path without data migration.
</objective>

Create `src/blocks/talk-meta/edit.js` exporting a default `TalkMetaPanels` component that renders four `PluginDocumentSettingPanel` instances.

**Imports:**
```javascript
import { PluginDocumentSettingPanel } from '@wordpress/editor';
import { useEntityProp } from '@wordpress/core-data';
import { useSelect } from '@wordpress/data';
import { useState, useEffect, useRef } from '@wordpress/element';
import { TextControl, TextareaControl, Button } from '@wordpress/components';
import apiFetch from '@wordpress/api-fetch';
import { addQueryArgs } from '@wordpress/url';
import { __ } from '@wordpress/i18n';
```

**useEntityProp pattern (applies to all panels):**
```javascript
const postType = useSelect(
    ( select ) => select( 'core/editor' ).getCurrentPostType(),
    []
);
const [ meta, setMeta ] = useEntityProp( 'postType', postType, 'meta' );
```
CRITICAL: Always spread when calling setMeta: `setMeta( { ...meta, 'key': value } )` — never pass just `{ key: value }` as it clobbers all other meta.

Guard at top: `if ( ! meta ) return null;`

**Panel 1 — Talk Summary** (name: "speekr-talk-summary", title: "Talk Summary"):
- TextareaControl, label: "Summary", value: meta['speekr-summary'] ?? '', onChange: updates speekr-summary via setMeta spread, rows: 5
- Note in code comment: "RichText not used — broken in PluginDocumentSettingPanel since WP 6.5 (Gutenberg issue #60524)"

**Panel 2 — Media Links** (name: "speekr-talk-media", title: "Media Links"):
Three TextControl fields, each with type="url", label and key:
- "YouTube URL" → _speekr_media_youtube
- "Vimeo URL" → _speekr_media_vimeo
- "Slides URL" → _speekr_media_slides
Each updates via setMeta spread with its own key.

**Panel 3 — Conference** (name: "speekr-talk-conf", title: "Conference"):
The speekr-conf meta is an object `{ name: string, url: string }`. Use a local helper:
```javascript
const conf = meta['speekr-conf'] ?? { name: '', url: '' };
const updateConf = ( key, value ) =>
    setMeta( { ...meta, 'speekr-conf': { ...conf, [key]: value } } );
```
Render two TextControl fields:
- label: "Conference Name", value: conf.name ?? '', onChange: (v) => updateConf('name', v)
- label: "Conference URL", value: conf.url ?? '', onChange: (v) => updateConf('url', v), type: "url"

**Panel 4 — Appears In** (name: "speekr-talk-appears-in", title: "Appears In", read-only):
Use useState/useEffect/useRef for debounced data fetch. Fetch on mount (not on search — this is a reverse lookup):

```javascript
const postId = useSelect(
    ( select ) => select( 'core/editor' ).getCurrentPostId(),
    []
);

const [ conferences, setConferences ] = useState( [] );
const [ loading, setLoading ] = useState( true );

useEffect( () => {
    if ( ! postId ) return;
    apiFetch( {
        path: addQueryArgs( '/wp/v2/speekr_conference', {
            per_page: 100,
            _fields: 'id,title,meta',
            status: 'any',
        } ),
    } ).then( ( posts ) => {
        const matches = posts.filter(
            ( p ) => p.meta && p.meta._speekr_conf_talk_ref === postId
        );
        setConferences( matches );
        setLoading( false );
    } ).catch( () => setLoading( false ) );
}, [ postId ] );
```

Render inside the panel:
- If loading: `<p>{ __( 'Loading…', 'speekr' ) }</p>`
- If conferences.length === 0: `<p>{ __( 'Not referenced by any conference.', 'speekr' ) }</p>`
- Otherwise: `<ul>` with `<li>` per conference showing `conf.title.rendered`

Note in comment: "Searches up to 100 conferences — acceptable limit for this plugin's use case."

**Export:** `export default TalkMetaPanels;`
