**Imports:**

```javascript
import { PluginDocumentSettingPanel } from '@wordpress/editor';

```

**Shared meta hook pattern (top of component):**
```javascript
const postType = useSelect(
    ( select ) => select( 'core/editor' ).getCurrentPostType(),
    []
);
const [ meta, setMeta ] = useEntityProp( 'postType', postType, 'meta' );
if ( ! meta ) return null;
```

CRITICAL: Always spread when calling setMeta. Never pass just `{ key: value }` — it clobbers all other meta fields.

**Panel 1 — Headshots** (name: "speekr-speaker-headshots", title: "Headshots"):

_speekr_headshots is `array of { id: integer, label: string }`.

```javascript
const headshots = meta._speekr_headshots ?? [];

const addHeadshot = ( media ) => {
    setMeta( {
        ...meta,
        _speekr_headshots: [ ...headshots, { id: media.id, label: '' } ],
    } );
};

const removeHeadshot = ( index ) => {
    const updated = headshots.filter( ( _, i ) => i !== index );
    setMeta( { ...meta, _speekr_headshots: updated } );
};

const updateLabel = ( index, label ) => {
    const updated = headshots.map( ( shot, i ) =>
        i === index ? { ...shot, label } : shot
    );
    setMeta( { ...meta, _speekr_headshots: updated } );
};

const reorder = ( fromIndex, toIndex ) => {
    const updated = [ ...headshots ];
    const [ moved ] = updated.splice( fromIndex, 1 );
    updated.splice( toIndex, 0, moved );
    setMeta( { ...meta, _speekr_headshots: updated } );
};
```

Render:
- List of headshots (`<div className="speekr-headshots-list">`). For each headshot at index:
  - Show `<img src={ `${ window.speekrData?.siteUrl ?? '' }/wp-json/wp/v2/media/${ shot.id }?_fields=source_url` }` — actually, use a simpler approach: render a div with the ID and a note about fetching. Or better: use wp.data to get attachment URL, but to keep it simple, render `<img src="" data-attachment-id={ shot.id } />` and resolve via apiFetch if time permits, OR just show the ID with label control since block editor doesn't need image preview for MVP.
  - **Simpler MVP approach**: Show `<span>Attachment #{ shot.id }</span>` + TextControl for label + "↑" / "↓" Button controls for reorder + "×" Button (isDestructive) to remove.
  - If index === 0: show `<span className="speekr-primary-badge">{ __('Primary', 'speekr') }</span>` badge.
  - Reorder: "↑" button calls reorder(index, index - 1) if index > 0; "↓" calls reorder(index, index + 1) if index < headshots.length - 1.
- Add button (after list):
  ```jsx
  <MediaUploadCheck>
      <MediaUpload
          onSelect={ addHeadshot }
          allowedTypes={ [ 'image' ] }
          render={ ( { open } ) => (
              <Button onClick={ open } variant="secondary">
                  { __( 'Add Headshot', 'speekr' ) }
              </Button>
          ) }
      />
  </MediaUploadCheck>
  ```

Note: Using ↑/↓ buttons for reorder instead of drag-and-drop. The Draggable component from @wordpress/components requires significant DOM wiring for drop targets. Arrow buttons are simpler, accessible, and fully functional for the MVP. Drag-to-reorder can be layered in a future enhancement.

**Panel 3 — Social Links** (name: "speekr-speaker-social", title: "Social Links"):

_speekr_social_links is `array of { platform: string, url: string, label: string }`.
Exactly 8 fixed platforms per CONTEXT.md: LinkedIn, Facebook, Instagram, Bluesky, Mastodon, X, GitHub, Personal website, plus "Other" (9 total options in dropdown).

```javascript
const socialLinks = meta._speekr_social_links ?? [];
const PLATFORMS = [
    { value: '', label: __( 'Select platform…', 'speekr' ) },
    { value: 'linkedin', label: 'LinkedIn' },
    { value: 'facebook', label: 'Facebook' },
    { value: 'instagram', label: 'Instagram' },
    { value: 'bluesky', label: 'Bluesky' },
    { value: 'mastodon', label: 'Mastodon' },
    { value: 'x', label: 'X' },
    { value: 'github', label: 'GitHub' },
    { value: 'personal', label: __( 'Personal website', 'speekr' ) },
    { value: 'other', label: __( 'Other', 'speekr' ) },
];

const [ newPlatform, setNewPlatform ] = useState( '' );
const [ newUrl, setNewUrl ] = useState( '' );
const [ newLabel, setNewLabel ] = useState( '' );

const addLink = () => {
    if ( ! newPlatform || ! newUrl ) return;
    const entry = { platform: newPlatform, url: newUrl, label: newLabel };
    setMeta( { ...meta, _speekr_social_links: [ ...socialLinks, entry ] } );
    setNewPlatform( '' );
    setNewUrl( '' );
    setNewLabel( '' );
};

const removeLink = ( index ) => {
    setMeta( {
        ...meta,
        _speekr_social_links: socialLinks.filter( ( _, i ) => i !== index ),
    } );
};
```

Render:
- Ordered list of existing links: `<ul>` with `<li>` per entry showing `entry.platform` (or `entry.label` if Other) + `entry.url` + "×" Button to remove
- Add form: SelectControl (options: PLATFORMS, value: newPlatform, onChange: setNewPlatform)
- If newPlatform is not empty: show TextControl for URL (type: "url", label: "URL", value: newUrl, onChange: setNewUrl)
- If newPlatform === 'other': also show TextControl for label (label: "Label", value: newLabel, onChange: setNewLabel)
- If newPlatform and newUrl: show Button "Add" (variant: "primary") calling addLink()
