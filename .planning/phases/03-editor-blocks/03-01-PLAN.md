  <name>Task 1: Create inc/blocks/blocks.php with block registration and Talk meta registration</name>
  <files>inc/blocks/blocks.php</files>
  <action>
Create a new file `inc/blocks/blocks.php`. Add an ABSPATH guard at the top (die if not defined). Implement two functions and hook both to `init`:

**Function 1: speekr_register_blocks()**
- Guard: if ( ! is_dir( SPEEKR_DIRNAME . '/build/blocks' ) ) return;
- Loop: foreach ( glob( SPEEKR_DIRNAME . '/build/blocks/*/block.json' ) as $block_json )
- Register: register_block_type( dirname( $block_json ) );
- Hook: add_action( 'init', 'speekr_register_blocks' );

**Function 2: speekr_register_talk_meta()**
Register these meta keys on the Talks CPT (use speekr_get_cpt_slug() for the post type — it returns 'talks'):

1. `speekr-summary` — type: string, single: true, show_in_rest: true, sanitize_callback: 'sanitize_textarea_field', auth_callback: current_user_can('edit_posts')

2. `speekr-conf` — type: object, single: true, show_in_rest with full schema:
   ```php
   'show_in_rest' => array(
       'schema' => array(
           'type'       => 'object',
           'properties' => array(
               'name' => array( 'type' => 'string' ),
               'url'  => array( 'type' => 'string', 'format' => 'uri' ),
           ),
           'additionalProperties' => false,
       ),
   ),
   ```
   No sanitize_callback (object types use schema validation). auth_callback: current_user_can('edit_posts').

3. `_speekr_media_youtube` — type: string, single: true, show_in_rest: true, sanitize_callback: 'esc_url_raw', auth_callback: current_user_can('edit_posts')

4. `_speekr_media_vimeo` — same as _speekr_media_youtube

5. `_speekr_media_slides` — same as _speekr_media_youtube

Note: These are NEW block-editor-only keys for media links. The legacy `speekr-media-links` key (complex serialized array used by classic editor) is NOT registered for REST — it stays as-is for classic editor only. Two save paths, different keys. This avoids schema complexity and REST 400 errors.

Hook: add_action( 'init', 'speekr_register_talk_meta' );
