**C. inc/blocks/blocks.php** — Add the enqueue hook.

Read the current file. Add a new function and hook after the existing functions:

```php
/**
 * Enqueue Speekr editor panel styles in the block editor.
 */
function speekr_enqueue_editor_panel_styles() {
    $asset_file = SPEEKR_DIRNAME . '/build/editor/style-speekr-panels.css';
    if ( ! file_exists( $asset_file ) ) {
        return;
    }
    wp_enqueue_style(
        'speekr-editor-panels',
        SPEEKR_URL . 'build/editor/style-speekr-panels.css',
        array( 'wp-edit-post' ),
        SPEEKR_VERSION
    );
}
add_action( 'enqueue_block_editor_assets', 'speekr_enqueue_editor_panel_styles' );
```

Check that SPEEKR_URL and SPEEKR_VERSION constants are defined in the plugin (they may be SPEEKR_PLUGIN_URL or similar — read the main plugin file or Speekr.php to verify the correct constant names). Use whatever URL constant the plugin already defines.
