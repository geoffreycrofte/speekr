<task type="auto">
  <name>Task 2: Create src/frontend/style.scss with corrected font paths</name>
  <files>src/frontend/style.scss</files>
  <action>
    Copy `assets/css/src/speekr.scss` to `src/frontend/style.scss`, then update the @font-face url() declarations.

    The current file has font paths relative to the source location (`assets/css/src/`):
    ```scss
    @font-face {
      font-family: 'speekr';
      src: url('../fonts/front/speekr.eot?pguas6');
      src: url('../fonts/front/speekr.eot?pguas6#iefix') format('embedded-opentype'),
           url('../fonts/front/speekr.ttf?pguas6') format('truetype'),
           url('../fonts/front/speekr.woff?pguas6') format('woff'),
           url('../fonts/front/speekr.svg?pguas6#icomoon') format('svg');
      font-weight: normal;
      font-style: normal;
    }
    ```

    These paths resolve to `assets/fonts/front/` from the source. When webpack compiles to `build/frontend/style.css`, the relative URL resolves relative to the OUTPUT location (`build/frontend/`), not the source. Two levels up from `build/frontend/` reaches the plugin root, so the correct path is `../../assets/fonts/front/`.

    Replace ALL four url() font paths in the @font-face block:
    - `url('../fonts/front/speekr.eot?pguas6')` → `url('../../assets/fonts/front/speekr.eot?pguas6')`
    - `url('../fonts/front/speekr.eot?pguas6#iefix') format('embedded-opentype')` → `url('../../assets/fonts/front/speekr.eot?pguas6#iefix') format('embedded-opentype')`
    - `url('../fonts/front/speekr.ttf?pguas6') format('truetype')` → `url('../../assets/fonts/front/speekr.ttf?pguas6') format('truetype')`
    - `url('../fonts/front/speekr.woff?pguas6') format('woff')` → `url('../../assets/fonts/front/speekr.woff?pguas6') format('woff')`
    - `url('../fonts/front/speekr.svg?pguas6#icomoon') format('svg')` → `url('../../assets/fonts/front/speekr.svg?pguas6#icomoon') format('svg')`

    All other content in the file is copied verbatim — no other changes.

    Do NOT delete or modify the original `assets/css/src/speekr.scss`. Cleanup happens in Plan 04.
  </action>
  <verify>
    1. `grep "fonts/front" src/frontend/style.scss` — should only show lines containing `../../assets/fonts/front/`, never `../fonts/front/`.
    2. `grep -c "../../assets/fonts/front/" src/frontend/style.scss` — should return 5 (five url() occurrences updated).
    3. `grep "../fonts/front/" src/frontend/style.scss` — should return nothing (no old paths remain).
  </verify>
  <done>src/frontend/style.scss exists with all content from the original speekr.scss, with all 5 @font-face url() paths updated to use `../../assets/fonts/front/speekr.*` relative to the build output location. No `../fonts/front/` paths remain.</done>
</task>
