- speekr/conference-archive: table of conferences ordered by date descending

Steps to verify in your local WordPress (MAMP):

**Step 1 — Block Inserter**
Create or edit any page. Open the block inserter, search "speekr" or browse the "Speekr"
category. Confirm all 5 blocks appear: Speaker Profile, Talks List, Single Talk,
Conference Archive, Conference Map.

**Step 2 — Speaker Profile**
Insert the Speaker Profile block. In the sidebar: confirm Layout select and Allow Download
toggle appear. Save and preview on the frontend. Confirm: headshot image, short bio, full bio,
social link icons (icon-only with screen-reader text), rider sections if populated.
Enable Allow Download → save → confirm "Download press kit" button appears on frontend.

**Step 3 — Talks List**
Insert the Talks List block. Preview on the frontend.
Confirm: talk cards show media visual, title, summary, conference date/location.
If topics exist: confirm horizontal pill tabs appear; clicking a topic tab hides non-matching
talks without page reload; clicking the active pill or "All" restores all talks.
If no talks: confirm friendly empty state message (editor sees a "Create your first talk" link).

**Step 4 — Single Talk**
Navigate to a single Talk post URL (Talks > any talk > View). Confirm:
- Media area shows video embed (if video meta set) or featured image or placeholder
- 16:9 wrapper maintained even with placeholder
- Summary, post content, conference reference section
- Resources section with slide/other links (if set)
- "Read full article" link only when "Make as article" is on

**Step 5 — Conference Archive**
Insert the Conference Archive block on any page. Preview. Confirm table columns:
Conference (linked to event URL if set), Date, Location, Talk (linked if blog post).

**Step 6 — Conference Map**
Insert the Conference Map block. In the editor: confirm grey placeholder appears (NOT a Leaflet map).
Preview on the frontend:
- Map renders with OpenStreetMap tile layer
- Pins appear for conferences with lat/lng coordinates
- Clicking a pin shows popup: name, date, city, talk title, event link
- Clusters appear when multiple conferences share a location
Check browser DevTools > Network: Leaflet files should NOT load on pages without the Conference Map block.

**Step 7 — PHP / JS errors**
Open wp-content/debug.log and confirm no new Speekr PHP warnings/errors.
Open browser console (F12) on a page with the Conference Map block — confirm no JS errors.
