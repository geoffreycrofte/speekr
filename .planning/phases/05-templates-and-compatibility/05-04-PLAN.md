**Where to add each require_once:**
- `templates.php` → in `includes()` AFTER `press-kit.php` line, BEFORE `do_action('speekr_after_includes')` — loads on all requests (admin + frontend) so Site Editor can register templates
- `shortcodes.php` → in `includes_front()` AFTER `single.php` line, BEFORE `do_action('speekr_after_includes_front')` — frontend only; admin/REST don't need shortcodes

**Talks CPT has_archive fix** (inc/cpt/talks.php):
The $args array in speekr_register_post_types() does not currently set `has_archive`. Add it before the apply_filters line. The rewrite slug for the archive is the same as the post type slug ('talks').
```php
'has_archive' => apply_filters( 'speekr_talks_has_archive', true ),
```
Adding the filter wrapper allows developers to disable the archive if they prefer a designated page. Add this line to the $args array.
