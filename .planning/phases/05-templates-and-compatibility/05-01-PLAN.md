**CRITICAL Phase 4 rules that still apply:**
- Never wrap the entire render.php in ob_start()/ob_get_clean() — WP wraps render.php in its own outer buffer
- Never declare named functions inside render.php (redeclare fatal) — use `$fn = static function(){}` closures
- Always echo directly (or use `?>...html...<?php` interleaving)

**Hook naming convention** (established in plugin):
- speekr_ prefix, snake_case
- before/after pairs: `speekr_before_{block}` / `speekr_after_{block}`
- Signature: `do_action( 'speekr_before_profile', $post_id, $attributes )`

**Per-talk output filter** (talks-list only):
- Handle: `speekr_talk_output`
- Signature: `apply_filters( 'speekr_talk_output', $html, $talk_post, $attributes )`
- Use local ob_start() to capture each `<article>` card HTML, then pass through filter
- This is a LOCAL ob_start() inside the foreach loop (not wrapping the whole file) — safe

**Block name → hook name mapping:**
| Block | Before hook | After hook |
|-------|-------------|------------|
| speaker-profile | speekr_before_profile | speekr_after_profile |
| talks-list | speekr_before_talks_list | speekr_after_talks_list |
| single-talk | speekr_before_single_talk | speekr_after_single_talk |
| conference-archive | speekr_before_conference_archive | speekr_after_conference_archive |
| conference-map | speekr_before_map | speekr_after_map |

**Variable names for $post_id in each render.php** (verify by reading each file before editing):
- speaker-profile/render.php: `$speaker_id` (integer, resolved at top of file)
- talks-list/render.php: no single post context; use `0` as $post_id

- conference-archive/render.php: read file to find post_id variable

- Wrap each article's HTML output in a local ob_start() / ob_get_clean() pair
- Pass the captured HTML through `apply_filters()`:

```php
ob_start();
?>
<article class="speekr-talk-card" ...>
    <?php /* existing card markup — no changes */ ?>
</article>

$talk_html = ob_get_clean();

```

This local ob_start() is safe — it captures only the article element inside the loop, not the whole file. The outer WP buffer wraps the whole render.php; this inner buffer pair is nested inside and resolves before the outer buffer collects the output.
