**Classic template pattern** (each file follows this structure):
```php
<?php
/**
 * Template: {description}
 *
 * Child theme override: place file at {get_stylesheet_directory()}/speekr/{filename}
 *
 * @package Speekr
 */
if ( ! defined( 'ABSPATH' ) ) {
    die( 'Cheatin\' uh?' );
}

get_header();
?>
<main id="primary" class="site-main speekr-classic-template">
    <?php
    $attributes = array(); // render.php defaults handle all attribute values
    require SPEEKR_DIRNAME . '/src/blocks/{BLOCK_NAME}/render.php';
    ?>
</main>
<?php
get_footer();
```

**Classic template → block render.php mapping:**
| Classic template file | Block render.php | Notes |
|----------------------|------------------|-------|
| speaker-profile.php | src/blocks/speaker-profile/render.php | is_singular('speekr_speaker') |
| archive-talk.php | src/blocks/talks-list/render.php | is_post_type_archive('talks') |
| single-talk.php | src/blocks/single-talk/render.php | is_singular('talks') |
| archive-conference.php | src/blocks/conference-archive/render.php | is_post_type_archive('speekr_conference') |
| single-conference.php | src/blocks/conference-archive/render.php | is_singular('speekr_conference') — reuses archive block |

**ob_start() in shortcode callbacks IS safe** (different from render.php restriction):
The Phase 4 rule "never use ob_start in render.php" applies only to render.php files wrapped by `register_block_type()`. Shortcode callbacks run in normal PHP flow — no outer buffer. Use ob_start() + require + ob_get_clean() to capture output.

**Shortcode attribute → $attributes camelCase key mapping** (locked decisions):
```
[speekr_profile layout="side-by-side|stacked" show_download="0|1"]
  → $attributes['layout']       = $atts['layout']
  → $attributes['allowDownload'] = (bool) $atts['show_download']   // camelCase matches block.json

[speekr_talks layout="grid|list" limit="<n>"]
  → $attributes['layout'] = sanitize_key( $atts['layout'] )
  → $attributes['limit']  = (int) $atts['limit']

[speekr_map height="<px>"]
  → $attributes['height'] = (int) $atts['height']   // verify key name against block.json
```

**Block CSS/JS handles and paths** (verify asset file names in build/blocks/ before using):
- speaker-profile: style-index.css (+ view.js if it has one)
- talks-list: style-index.css + view.js (topic filter)
- conference-map: style-index.css + view.js (Leaflet)

**Plugin constants:**
- `SPEEKR_DIRNAME` — absolute path to plugin root (no trailing slash)
- `SPEEKR_PLUGIN_URL` — URL to plugin root (with trailing slash)
- `SPEEKR_VERSION` — plugin version string

Create `inc/front/shortcodes.php`. This file registers 3 shortcodes. Do not load this file from Speekr.php in this task — wiring happens in Plan 04.

**Critical pattern:** shortcode callbacks use ob_start() + require + ob_get_clean(). This is safe and required — shortcodes must return output. This is DIFFERENT from the render.php restriction (which applies only to files wrapped by register_block_type()).

Before building $attributes, read each block's block.json to confirm attribute key names:
- `src/blocks/speaker-profile/block.json` for `layout`, `allowDownload`, `speakerId`
- `src/blocks/talks-list/block.json` for `layout`, `limit` (or similar)
- `src/blocks/conference-map/block.json` for `height` or equivalent

For enqueue handles, check the registered handles in `inc/front/enqueues.php` to reuse existing handles (to trigger WP deduplication). If handles are not pre-registered, enqueue using the block folder name as the handle base.

Structure:
```php
<?php
/**
 * Speekr Shortcodes
 *
 * [speekr_profile] - renders the speaker profile block
 * [speekr_talks]   - renders the talks list block
 * [speekr_map]     - renders the conference map block
 *
 * @package Speekr
 */
if ( ! defined( 'ABSPATH' ) ) {
    die( 'Cheatin\' uh?' );
}

/**
 * [speekr_profile layout="side-by-side|stacked" show_download="0|1"]
 */
function speekr_shortcode_profile( $atts ) {
    $atts = shortcode_atts( array(
        'layout'        => 'side-by-side',
        'show_download' => 0,
    ), $atts, 'speekr_profile' );

    $attributes = array(
        'layout'        => sanitize_key( $atts['layout'] ),
        'allowDownload' => (bool) $atts['show_download'],
    );

    wp_enqueue_style(
        'speekr-speaker-profile-style',
        SPEEKR_PLUGIN_URL . 'build/blocks/speaker-profile/style-index.css',
        array(),
        SPEEKR_VERSION
    );

    ob_start();
    require SPEEKR_DIRNAME . '/src/blocks/speaker-profile/render.php';
    return ob_get_clean();
}
add_shortcode( 'speekr_profile', 'speekr_shortcode_profile' );

/**
 * [speekr_talks layout="grid|list" limit="-1"]
 */
function speekr_shortcode_talks( $atts ) {
    $atts = shortcode_atts( array(
        'layout' => 'grid',
        'limit'  => -1,
    ), $atts, 'speekr_talks' );

    $attributes = array(
        'layout' => sanitize_key( $atts['layout'] ),
        'limit'  => (int) $atts['limit'],
    );

    wp_enqueue_style(
        'speekr-talks-list-style',
        SPEEKR_PLUGIN_URL . 'build/blocks/talks-list/style-index.css',
        array(),
        SPEEKR_VERSION
    );
    wp_enqueue_script(
        'speekr-talks-list-view',
        SPEEKR_PLUGIN_URL . 'build/blocks/talks-list/view.js',
        array(),
        SPEEKR_VERSION,
        true
    );

    ob_start();
    require SPEEKR_DIRNAME . '/src/blocks/talks-list/render.php';
    return ob_get_clean();
}
add_shortcode( 'speekr_talks', 'speekr_shortcode_talks' );

/**
 * [speekr_map height="400"]
 */
function speekr_shortcode_map( $atts ) {
    $atts = shortcode_atts( array(
        'height' => 400,
    ), $atts, 'speekr_map' );

    $attributes = array(
        'height' => (int) $atts['height'],
    );

    wp_enqueue_style(
        'speekr-conference-map-style',
        SPEEKR_PLUGIN_URL . 'build/blocks/conference-map/style-index.css',
        array(),
        SPEEKR_VERSION
    );
    wp_enqueue_script(
        'speekr-conference-map-view',
        SPEEKR_PLUGIN_URL . 'build/blocks/conference-map/view.js',
        array(),
        SPEEKR_VERSION,
        true
    );

    ob_start();
    require SPEEKR_DIRNAME . '/src/blocks/conference-map/render.php';
    return ob_get_clean();
}
add_shortcode( 'speekr_map', 'speekr_shortcode_map' );
```
